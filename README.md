## The image

A giant brass clockwork spider — hammered brass body, segmented abdomen,
eight jointed legs, about the size of a large dog — erupting out of an open
antique pocket watch on a scarred wooden watchmaker's bench. The watch has
burst: a tight radial spray of brass gears, cogs, mainsprings and tiny
screws frozen mid-air around the spider. At the left edge of the frame the
watchmaker recoils backwards off his stool, arms thrown up, loupe still in
one hand, face lit from below by a warm tungsten lamp. Low camera angle at
bench level, dark background, one dominant subject — the shape still reads
at thumbnail size.

The idea: the smallest thing in the room (a pocket watch) giving birth to
the biggest thing in the frame. Scale inversion, one warm light source,
and a burst that is all mechanism — no explosion, no firework.

## How to run

```sh
node main.ts
```

The program copies `entry.png` into the output directory
(`MAKEFUN_OUTPUT_DIR`, or `/output` by default). Standard library only —
no dependencies, no network. Running it twice produces identical bytes.
