## The image

A giant brass clockwork spider — hammered brass body, eight jointed legs,
about the size of a large dog — erupting out of an open antique pocket watch
on a scarred wooden watchmaker's bench. The watch has burst: gears, cogs,
mainsprings and tiny screws frozen mid-air in a tight radial spray. At the
left edge of the frame the watchmaker recoils off his stool, loupe still in
hand, lit from below by a warm tungsten lamp. Low camera angle, dark
background, one dominant subject — the shape still reads at thumbnail size.

The idea: the smallest thing in the room (a pocket watch) giving birth to
the biggest thing in the frame. Scale inversion, one warm light source,
and a burst that is all mechanism — no explosion, no firework.

## How to run

```sh
node main.ts
```

The program copies `entry.png` into the output directory
(`MAKEFUN_OUTPUT_DIR`, or `/output` by default). Standard library only —
no dependencies, no network. Running it twice produces identical bytes.
